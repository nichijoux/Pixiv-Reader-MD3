# 工作区文件操作范围限制

本规则（TTSR）强制 omp 只能操作当前项目目录 `F:\pixiv-mateiral3` 内的文件。

## 触发条件（任一）

1. **绝对路径指向项目外**：工具参数中出现盘符路径，且不是 `f:\pixiv-mateiral3\...`（例如 `C:\Users\...`、`D:\...`、`f:\other` 等），包括 JSON 转义形式（`C:\\Users\\...`）与正斜杠形式。
2. **父目录穿越**：任何 `..\` / `../` / `..\\` 形式的路径（会逃出项目根目录）。
3. **远程文件访问**：`ssh://` 形式的内部 URL（读取远程机器文件）。

## 合规写法

- 读写项目内文件一律使用**相对路径**（如 `app/src/main/...`），或 `F:\pixiv-mateiral3\...` 绝对前缀。
- 不要用 `..` 引用项目外文件；不要直接读取/修改项目目录外的任何文件。

## 例外与说明

- 构建工具链路径（如 `C:\Users\nichijoux\.jdks\...` 的 JDK、SDK）出现在 bash 命令参数中仅属"使用"，不算违规文件操作；本规则一次中断提醒后即放行，不会死循环。
- 规则只扫描工具调用参数（`scope: tool`），不扫描普通文本。文件内容中出现的 Windows 路径（如测试数据）不触发，因为条件匹配的是工具参数文本。
- 规则对 Unix 绝对路径（`/data/...`、`/storage/...` 等 Android 路径）不设防——本机为 Windows，真实文件操作均走盘符路径或相对路径。
