该选哪个？

打开系统设置 → 关于手机，查看处理器信息：64 位（绝大多数机型）选 arm64-v8a；只能看到 32 位字样的老机器选 armeabi-v7a。架构不匹配时系统会提示「应用未安装」。

使用方法

四步开始使用

全程约两分钟，无需任何额外配置。

  1. 1

    下载 APK

    从上方选择对应架构的安装包，或到 GitHub Releases 页面下载。

  2. 2

    允许安装未知应用

    Android 8+ 首次安装会提示，需在系统设置中允许你的浏览器或文件管理器「安装未知应用」，属正常系统提示。

  3. 3

    安装并打开

    点击下载的 APK 完成安装。覆盖安装会保留历史、下载与阅读进度。

  4. 4

    登录 pixiv 账号

    首次启动引导登录，走 pixiv 官方 OAuth 授权，密码只在 pixiv 官方页面输入，本应用不经手。

数据保存在哪？

浏览历史、搜索记录、下载与阅读进度全部只存在本机数据库中，卸载应用即清空。

如何更新？

应用内「我的 → 检查更新」会读取 GitHub Releases；也可以直接下载新 APK 覆盖安装。

常见问题

你可能想问

需要 pixiv 账号吗？

需要。首次启动会引导登录，走 pixiv 官方 OAuth 授权（PKCE），密码只在 pixiv 官方页面输入，本应用不经手、不存储。

使用第三方客户端会不会封号？

本应用为非官方客户端，使用第三方客户端访问 pixiv 存在理论上的账号风险，请自行评估后使用。项目仅供学习交流，作者不对账号问题负责。

我的数据安全吗？存在哪里？

浏览历史、搜索记录、下载与阅读进度全部只存在本机 Room 数据库中，应用不上传、不收集任何数据，也没有任何统计 SDK。

为什么只有 ARM 架构的 APK？

Release 按 ABI 拆分以减小体积，覆盖 arm64-v8a 与 armeabi-v7a 两种架构，已覆盖 virtually 全部 Android 手机与平板；x86 设备与模拟器不在支持范围内。

安装时提示「未知来源」怎么办？

Android 8.0 起系统要求逐应用授权：在弹出的设置页中，允许你用来下载 APK 的浏览器或文件管理器「安装未知应用」，返回后重新安装即可。

怎么更新到新版本？

应用内「我的 → 检查更新」会读取 GitHub Releases 并展示更新说明；也可以直接到本页或 Releases 页下载新 APK 覆盖安装，本地数据全部保留。

支持平板吗？

支持。窗口宽度 ≥600dp 自动切换为左侧导航栏，≥704dp 排行榜展开「列表 + 详情 / 评论」双栏，正文限宽 760dp 居中，横竖屏均可。

和 Pixiv-Shaft 是什么关系？

没有从属关系。PixivReader 是独立项目，API 层参考并借鉴了开源项目 Pixiv-Shaft 与 pixiv-api-kotlin，均遵循 GPL-2.0，已在页脚致谢。
